# TimeDuet

### A Benchmark for Audio-Visual Temporal Grounding on Misaligned Streams

[Code](https://github.com/TimeDuet/TimeDuet) · [Dataset](https://huggingface.co/datasets/TimeDuet/TimeDuet) · [Model](https://huggingface.co/TimeDuet/TimeDuet-Qwen)

TimeDuet evaluates audio-visual temporal grounding under controlled temporal misalignment, with separate audio and visual ground-truth intervals. It provides a benchmark, fine-grained evaluation, and supervised fine-tuning and reinforcement learning for balanced grounding.
